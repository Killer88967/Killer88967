## About Me

I'm a full-stack developer who spends most of my time building web apps, developer tools, Discord systems, frameworks, and games.

I like projects where I can dig below the surface instead of only assembling existing libraries — whether that's designing a database protocol, building a visual editor, creating custom framework tooling, or experimenting with multiplayer game systems.

Currently, a lot of my work revolves around **TypeScript**, **React / Next.js**, **Node.js**, developer tooling, backend architecture, and realtime systems.
